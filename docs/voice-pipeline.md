# Voice pipeline: update a translation, regenerate the voice

Whale-chan's Japanese voice is a generated artifact. This is the operating manual
for changing what she says and rebuilding the audio.

Nothing here is needed to *use* the plugin — only to change it.

---

## 1. What is source, what is generated

| Path | Role | Edit by hand? |
|---|---|---|
| `assets/whale-moe-core.js` | **Source.** The 653 English lines (41 `LINES` + 612 `DIALOGUE`) | yes |
| `assets/dsh-whale-moe.js` | **Source.** The presenter; looks clips up by the exact English line | yes |
| `scripts/voice-pilot.mjs` | **Source.** Line selection, translation store, job builder, `EXTRAS` | yes |
| `.voice-preview/ja/part-01..06.json` | **Source.** The translation batches (durable home of every Japanese line) | yes |
| `.voice-preview/ja-translations.json` | Generated by `--merge`; rebuilt from the parts | only if you never re-run `--merge` |
| `.voice-preview/job.json`, `all-lines.json`, `lines*.tsv` | Generated by `--all` / `--batches` | no |
| `.voice-preview/wav/clean/jf_tebukuro/*.wav` | Generated masters (183 MB, 24 kHz mono) | no |
| `assets/voice/ja/**` | Generated **shipping** pack: 654 `.ogg` + `manifest.json` | no |
| `.voice-preview/{manifest,pack}.json` | Generated telemetry (duration, peak, SNR, phonemes, source text) | no |

`.voice-preview/` is git-ignored; `assets/voice/ja/` is committed (15.7 MB).

The manifest maps **the exact English line string** to a clip file, e.g.
`"Clang clang, the tools are spinning up." -> "jf_tebukuro/…-i1.ogg"`. That is the
contract between the pack and the presenter: if the English text changes, the key
changes, and the old clip becomes an orphan.

## 2. One-time setup

Only needed on a fresh clone (the venv and models are git-ignored).

```powershell
cd <repo>
# keep uv's cache inside the workspace so it works in a sandboxed shell
$env:UV_CACHE_DIR          = "$PWD\.voice-preview\.uv-cache"
$env:UV_PYTHON_INSTALL_DIR = "$PWD\.voice-preview\.uv-python"

uv venv .voice-preview/.venv --python 3.12
uv pip install --python .voice-preview/.venv/Scripts/python.exe `
  "kokoro-onnx==0.6.1" "misaki-fork==0.9.6" "pyopenjtalk-plus==0.4.1.post9" soundfile

# ~192 MB: kokoro-v1.0.fp16.onnx + voices-v1.0.bin
node scripts/voice-pilot.mjs --setup
```

Python 3.12 specifically: `pyopenjtalk` has no Windows wheel on 3.13, which is why
`pyopenjtalk-plus` (same `import pyopenjtalk`, ships wheels) is pinned instead.

## 3. Quick reference

```powershell
# rebuild the merged translation store from the parts, then the render job
node scripts/voice-pilot.mjs --merge
node scripts/voice-pilot.mjs --all

# synthesize (add --only-missing to skip clips whose text is unchanged)
.\.voice-preview\.venv\Scripts\python.exe scripts/kokoro-render.py `
  --job .voice-preview/job.json --variants clean --voices jf_tebukuro --only-missing

# compress into the shipping pack (SNR-gated) and refresh the runtime manifest
.\.voice-preview\.venv\Scripts\python.exe scripts/voice-pack.py `
  --out assets/voice/ja --manifest assets/voice/ja/manifest.json

# install into the running DSH (assets only) and hard-refresh the page
node scripts/apply-theme.mjs --assets-only --target "<DSH_INSTALL_DIR>"
```

Verify afterwards:

```powershell
npm test                 # 122 unit tests
npm run qa:voice         # headless Chrome, real playback assertions (Node 22+ for the global WebSocket)
npm run qa:voice:watch   # the same, audible and visible
```

## 4. Recipe: change one translation

The common case. Example: reword `DIALOGUE.work.tool#1`.

1. **Find the key.** Line keys are `<path>#<index>`:

   ```powershell
   Select-String -Path .voice-preview\lines.all.tsv -Pattern 'Clang clang'
   # 163  DIALOGUE.work.tool#1  Clang clang, the tools are spinning up.  …
   ```

   or open `.voice-preview/lines.all.tsv` (n, key, English, Japanese).

2. **Edit the Japanese in the durable place**: the `part-NN.json` that holds that
   key. `--merge` rebuilds `ja-translations.json` from the parts, so an edit made
   only in the merged file is lost the next time you merge. (Editing the merged
   file is fine *if* you then skip `--merge`.)

3. **Rebuild and re-synthesize:**

   ```powershell
   node scripts/voice-pilot.mjs --merge
   node scripts/voice-pilot.mjs --all
   .\.voice-preview\.venv\Scripts\python.exe scripts/kokoro-render.py --job .voice-preview/job.json --variants clean --voices jf_tebukuro --only-missing
   ```

   Expect exactly one fresh clip:

   ```
   rendered:
     (653 clip(s) reused from the previous manifest, 1 freshly synthesized)
   ```

   `--only-missing` re-renders when the recorded **text**, voice, speed or size
   differs from what produced the existing file — so an edited translation is
   never silently reused.

4. **Repack and install:**

   ```powershell
   .\.voice-preview\.venv\Scripts\python.exe scripts/voice-pack.py --out assets/voice/ja --manifest assets/voice/ja/manifest.json
   node scripts/apply-theme.mjs --assets-only --target "<DSH_INSTALL_DIR>"
   ```

5. **Hard-refresh** the GUI (`Ctrl+Shift+R`). Only a page refresh is needed for
   asset changes; see §9.

Rendering 654 clips from scratch takes ~4 minutes; repacking ~2. Both are fine as
background jobs.

## 5. Recipe: retranslate many lines

1. `node scripts/voice-pilot.mjs --batches 6` writes `.voice-preview/all-lines.json`
   and six balanced `ja/batch-NN.json` files (key → English). Batches are split by
   character count, not line count.
2. Produce `ja/part-NN.json` (key → Japanese, same keys) — by hand, or by fanning
   the batches out to translators/agents. One part file per batch.
3. `node scripts/voice-pilot.mjs --merge` validates and merges. It refuses to write
   the store and prints the offending keys when anything is wrong (see §7).
4. Continue with `--all` → render → pack → install as in §4.

Only the batches you touch need a `part-NN.json`; the merge tolerates a subset as
long as every key is eventually covered.

## 6. Recipe: the lines the presenter writes itself

Most bubbles come from a core bank, but a few are fixed strings in the presenter.
Those live in `EXTRAS` in `scripts/voice-pilot.mjs`:

```js
const EXTRAS = [
  { key: "PRESENTER.celebrate", …, en: "Ehehe~ I like Master best!", ja: "えへへ～、…" }
];
```

The critical rule: **`en` must be exactly the literal the presenter passes to
`playVoiceFor()`**, because the manifest key is that literal and the lookup is an
exact string match. If you change one side, change the other. The test
`every voiced line has a clip, and no clip is orphaned` fails if they drift apart.

After editing `EXTRAS`, run the same §4 steps (merge → all → render → pack →
install). New entries get the next `n`, so their filenames are new.

Dynamically composed announcements — `"Achievement unlocked: " + label + "!"` — are
interpolated per event and have **no** clips. They are handed to the optional MiMo
TTS bridge instead. Pre-rendering each achievement name and concatenating is
possible but not implemented.

## 7. What a translation must satisfy

`--merge` and `--all` enforce these; a violation stops the pipeline instead of
shipping a broken clip.

- **Every key covered, exactly once.** Missing, duplicate and stale keys are listed.
- **No `Master` / `Whale-chan` in core-line translations.** They are placeholders;
  use `マスター` and `くじらちゃん` so the plugin's own naming still matches.
- **Must contain Japanese characters** (kana/kanji) — an untranslated leftover fails.
- **`~` is normalised to `～`**; emoji and kaomoji are stripped for speech
  automatically, so they are harmless in the bubble text and never spoken.
- **Keep the line about as long as the English.** The bubble types out, so a much
  longer line reads as a delay; the current set averages ~35 Japanese characters.
- **Vocabulary check.** The renderer asserts that the model vocabulary accepts every
  phoneme; unusual katakana can drop phonemes and will be reported.
- **Rare G2P crash.** `misaki`+`pyopenjtalk` abort on some readings (notably
  「間」 → `pron=マ` with `mora_size=3`, so any 「…間も」). The renderer catches this,
  falls back to the kana reading, and prints
  `~~ <key> used the kana-fallback: …` — that line is informational, not a failure.

## 8. Changing the voice or the speed

- Voice: `FULL_VOICES` in `scripts/voice-pilot.mjs` (Japanese voices available in
  `voices-v1.0.bin`: `jf_alpha`, `jf_gongitsune`, `jf_tebukuro`, `jf_nezumi`,
  `jm_kumo`). To compare them, listen to `.voice-preview/index-pilot.html`, which
  plays the 10 pilot lines from all four female voices side by side
  (`index-pack.html` plays the shipped set and is regenerated on every pack).
- Speed: `speed` in the job (`--speed` on the renderer). A different speed or voice
  invalidates every cached clip by design, so `--only-missing` re-renders all of
  them — that is the correct outcome, not a bug.

After a voice change, the pack directory gains a sibling
(`assets/voice/ja/<newVoice>/`) and the manifest's `voice` field changes; the
presenter needs no code change because it reads the manifest.

## 9. Install and refresh matrix

| What changed | How it reaches the browser |
|---|---|
| `.ogg` clips, `manifest.json`, `dsh-whale-moe.js`, CSS | `apply-theme.mjs --assets-only --target "<DSH_INSTALL_DIR>"`, then **hard refresh** |
| `lib/index.js` (host asset route, MIME types) | **DSH restart** — the host half is loaded at startup |
| `lib/client.js` (bundle half: settings section, `VOICE_ROOT` rewrite) | bundle/profile update + DSH restart |
| `apply-theme.mjs` itself | nothing to install; it runs on your machine |

In theme mode the files land in
`<DSH_INSTALL_DIR>/node_modules/@deepseek-ai/dsh-web-frontend/dist/assets/voice/ja/`.
Do not edit them there — they are copies; fix the repo and re-install.

## 10. Traps worth knowing

- **`n` is the job order.** It becomes the filename prefix (`163-dialogue-work-tool-i1.ogg`).
  Inserting or removing a core line renames every later file, so a rebuild will
  re-render and re-pack them all. Deterministic, just not incremental.
- **Changing an English line re-keys its clip.** The manifest is keyed by the English
  text, so the old clip becomes an orphan. The coverage test reports orphans and
  missing keys; re-run the whole chain after such an edit.
- **`.voice-preview/` is throwaway but slow to rebuild.** It holds 183 MB of WAV
  masters plus the model files; deleting it means re-downloading and re-rendering.
- **The first `--only-missing` run after this version is a full run.** Older manifests
  have no recorded source text, so nothing can be proven unchanged. One-time cost
  (~4 minutes); afterwards it is genuinely incremental.
- **Failures are meant to be loud.** The renderer fails on silence, wrong sample
  rate, absurd duration or dropped phonemes; the packer fails below 15 dB SNR. Both
  exist because libsndfile's Opus encoder shipped ~7 dB SNR output at any bitrate,
  which is why the pack is Vorbis.

## 11. Seeing why a bubble was silent

The presenter keeps a bounded log in the page:

```js
__dshWhaleVoice
// { loaded: true, clips: 654, blocked: false,
//   misses: [ { line: "Achievement unlocked: …", reason: "not-in-pack" }, … ] }
```

Reasons: `voice-off`, `bubbles-off`, `manifest-not-loaded`, `not-in-pack`,
`autoplay-blocked`, `autoplay-refused`, `playback-error`. `not-in-pack` is the only
one that means a clip is missing; the rest are toggles, timing or browser policy.
